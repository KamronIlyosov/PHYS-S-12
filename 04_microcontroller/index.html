Week 04 · Microcontroller

Microcontroller Programming

My first real Arduino project. 16 LEDs arranged in two faces (one smiley, one sad), and a potentiometer you turn to switch between them.

How it works

The potentiometer is just a variable resistor with a wiper, so when I connect the 2 outer pins to power and ground, the middle pin gives me a voltage that goes from 0V to 3.3V depending on where the knob is. The microcontroller reads that voltage on analog pin A0 and converts it into a number from 0 to 4095 (12 bit ADC). The number changes smoothly as I turn the knob, so I can use it as a single input that picks between two outcomes by comparing it to a threshold.

I set two thresholds, one at 1900 and one at 2200, so anything below 1900 shows the smiley face on pin D1 and anything above 2200 shows the sad face on pin D2. The gap in between is a dead zone where neither face is on, which keeps the LEDs from flickering when the pot is sitting right at the boundary. The two sets of LEDs are wired in parallel groups so a single digital pin can drive each face, with current limiting resistors in series so the LEDs don't pull more than they can handle.

The code

I started with the obvious version that used delay() between readings, but delay() blocks the whole loop, which means while the microcontroller is "waiting" it can't read the potentiometer or do anything else. The instructor mentioned using millis() instead, which tracks how long the program has been running and only does work when enough time has passed. So I rewrote the loop to check millis() against a saved timestamp every 50ms instead of blocking. The result is the same on the surface but the code can do other things in between reads, which is useful for any future project that has more going on. 

const int potPin = A0;
const int ledSetA = D1;
const int ledSetB = D2;

unsigned long previousMillis = 0;
const long interval = 50; // 50ms interval

void setup() {
  pinMode(ledSetA, OUTPUT);
  pinMode(ledSetB, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  unsigned long currentMillis = millis();

  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis;

    int potValue = analogRead(potPin);
    Serial.println(potValue);

    if (potValue < 1900) {
      digitalWrite(ledSetA, HIGH);
      digitalWrite(ledSetB, LOW);
    } else if (potValue > 2200) {
      digitalWrite(ledSetA, LOW);
      digitalWrite(ledSetB, HIGH);
    } else {
      digitalWrite(ledSetA, LOW);
      digitalWrite(ledSetB, LOW);
    }
  }
}

Building the circuit

The build took 1 potentiometer, 16 LEDs split into 2 groups, 4 resistors, and 19 wires. I connected D1 to the positive leg of the smiley LEDs through a current limiting resistor, and D2 to the positive leg of the sad LEDs through another resistor. Both groups share a common ground. The potentiometer outer pins go to 3.3V and GND, and the middle pin goes to A0. After uploading the code and turning the knob, the faces switched right when they were supposed to.

What I took away

Two things stuck. One, the difference between digital and analog input, the LEDs are binary on or off but the input is a continuous value, and the code is what bridges those two worlds with threshold logic. Two, that delay() is fine for simple sketches but kills you the moment a project needs to do more than one thing, so millis() is worth getting comfortable with early. Both of those came up again in basically every project after this.
