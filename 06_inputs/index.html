Sensors: Pressure and Light

Two builds, a foam and copper capacitive pressure sensor, and a light sensor that switches an LED based on how dark the room is.

Assignment 1: Capacitive Pressure Sensor

The idea here is that a capacitor's behavior changes with the distance between its plates, so if I put a soft material between 2 conductive plates and then squish them together with weight on top, the capacitance changes in a measurable way. I built mine with 2 small copper sheets sandwiching a piece of soft foam. The microcontroller charges one plate through a TX pin, then reads the analog voltage at the other plate. The reading depends on how much charge transferred across the gap, which depends on the capacitance, which depends on the foam thickness, which depends on how much weight is on top. So pressing harder gives a higher number.

Step 1: Building the sensor

The build is simple, 2 copper sheets with a foam pad between them, wires soldered to each copper sheet. One sheet goes to pin D0 (analog read), the other to D3 (the TX pin that pulses high and low). When weight pushes down on the foam the foam compresses, the plates get closer, the capacitance increases, and the reading goes up.

  • Top copper sheet — D0 (analog read)
  • Bottom copper sheet — D3 (TX pulse)

Step 2: Initial code (uncalibrated)

This is the starting code I pulled from the S-12 site. It pulses the TX pin high and low 100 times in a row, reading the analog pin at each transition, and adds up the differences. The total at the end is the raw sensor value. It doesn't mean anything in real units yet, it's just a number that goes up when you press harder. 

long result;
int analog_pin = A3;
int tx_pin = 4;

void setup() {
  pinMode(tx_pin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  result = tx_rx();
  Serial.println(result);
}

long tx_rx() {
  int read_high, read_low, diff;
  long sum = 0;
  int N_samples = 100;

  for (int i = 0; i < N_samples; i++) {
    digitalWrite(tx_pin, HIGH);
    read_high = analogRead(analog_pin);
    delayMicroseconds(100);
    digitalWrite(tx_pin, LOW);
    read_low = analogRead(analog_pin);
    diff = read_high - read_low;
    sum += diff;
  }
  return sum;
}

Step 3: Calibration

To turn the raw number into grams I needed a calibration curve, so I put known weights on the sensor one at a time and recorded what the sensor reported. Here is what I got:

The relationship between weight and sensor value isn't perfectly linear (foam doesn't compress the same amount per gram once it's already squished), but across the 0g to 500g range it's close enough that a straight line works as a rough estimator.

Step 4: Updated code with weight estimation

I added a function that takes the raw reading and maps it to a weight in grams using the Arduino map() function. My first attempt mapped 60,000 to 140,000 → 0g to 1000g, but the values came out way too high (a 100g object was reading like 600g). So I tightened the range to 0g to 500g and got readings that were a lot closer to true weight. 

long result;
int analog_pin = A3;
int tx_pin = 4;

void setup() {
  pinMode(tx_pin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  result = tx_rx();
  float weight = estimateWeight(result);
  Serial.print("Reading: ");
  Serial.print(result);
  Serial.print(" | Est. Weight (g): ");
  Serial.println(weight);
}

float estimateWeight(long reading) {
  if (reading <= 60000) return 0;
  if (reading >= 140000) return 500;
  return map(reading, 60000, 140000, 0, 500);
}

long tx_rx() {
  int read_high, read_low, diff;
  long sum = 0;
  int N_samples = 100;

  for (int i = 0; i < N_samples; i++) {
    digitalWrite(tx_pin, HIGH);
    read_high = analogRead(analog_pin);
    delayMicroseconds(100);
    digitalWrite(tx_pin, LOW);
    read_low = analogRead(analog_pin);
    diff = read_high - read_low;
    sum += diff;
  }
  return sum;
}

Testing on a real object

To check the accuracy, I weighed my AirPods on an actual digital scale and got 50g, then put them on the sensor and read about 55g. 5g off across a 50g object is roughly 10% error, which is good enough for a handmade capacitive sensor and it proves the sensor is responding to real weight, not just noise.

Assignment 2: Light Sensor with LED Control

Second build was simpler, a photoresistor (its resistance drops as light increases) hooked up to an analog pin, and an LED on a digital pin. The microcontroller reads the analog value every 100ms, estimates how bright the room is in lux, and turns the LED on if the room is below a threshold. So if you walk into a dark room the LED lights up automatically, and when you turn the room lights back on the LED turns off.

Demo

Step 1: Wiring

The photoresistor sits in a voltage divider with a 10k resistor, with the midpoint going to analog pin A0. The LED is on pin D10 through a 1k current limiting resistor. Power and ground go to 3.3V and GND like everything else.

  • Light sensor — A0 (D0)
  • LED — D10
  • Power and GND wired in the usual way

Step 2: The code

Same trick as Week 4, I'm using millis() instead of delay() so the loop stays responsive. Every 100ms it reads the analog pin, converts the raw value to a rough lux estimate, and compares against a threshold of 100 lux. Below 100 the LED turns on, above 100 it turns off. 

const int sensorPin = D0;
const int ledPin = D10;

unsigned long lastReadTime = 0;
const unsigned long readInterval = 100;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  unsigned long currentTime = millis();
  if (currentTime - lastReadTime >= readInterval) {
    lastReadTime = currentTime;

    int sensorValue = analogRead(sensorPin);
    float lux = estimateLux(sensorValue);

    Serial.print("Raw: ");
    Serial.print(sensorValue);
    Serial.print(" | Estimated Lux: ");
    Serial.println(lux);

    if (lux < 100) {
      digitalWrite(ledPin, HIGH);
    } else {
      digitalWrite(ledPin, LOW);
    }
  }
}

float estimateLux(int analogVal) {
  int inverted = 4095 - analogVal;
  float lux = map(inverted, 0, 4095, 0, 1000);
  return constrain(lux, 0, 1000);
}

Step 3: Calibrating the sensor

The photoresistor's raw value is between 0 and 4095, and bigger values actually mean less light (because more resistance = lower voltage at the divider midpoint, which the ADC reads as a smaller number… and I'm inverting it in the code so up is brighter). To turn that into a lux estimate I measured the sensor under a few known lighting conditions:

ConditionAnalog valueApprox. Lux
Direct flashlight300~900
Room light1200~154
Shadow2500~70
Dark room3500+<10

Then I inverted the value and mapped it into a 0–1000 lux range with the same map() approach:

int inverted = 4095 - analogVal;
float lux = map(inverted, 0, 4095, 0, 1000);

The result isn't calibrated against an actual lux meter, but it gives a usable number where 0 = pitch dark and 1000 = bright daylight, which is all I needed for the on/off threshold.

Step 4: Testing the LED

Final test, cover the sensor with my hand and the LED switches on, uncover it and the LED switches off. The threshold of 100 lux is right around the level of a dim room, so a desk lamp on across the room keeps the LED off but turning all the lights off triggers it within a few hundred milliseconds.

What I took away

Both of these are basically the same idea, take a real world signal (pressure, light), turn it into an analog voltage, read it on the microcontroller, and use a threshold to decide what to do. The pressure sensor is more interesting because I had to build the sensor itself from foam and copper, and calibrate it against known weights. That same calibration approach shows up in Week 7 when I use a Hall sensor to detect steps, so getting comfortable with the idea here saved me time later.
